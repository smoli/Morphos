# App-Dateisystem & Berechtigungen

Erzeugte Apps dürfen optional Dateien lesen/schreiben — über eine kontrollierte
postMessage-Brücke, strikt auf einen Datenordner eingegrenzt, mit einer
Berechtigung je Funktion (Fragen/Erlauben/Ablehnen).
