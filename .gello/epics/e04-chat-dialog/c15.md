# Rückfragen des LLM (MORPHOS:SAY)

Ist ein Wunsch unklar, stellt das LLM eine Rückfrage (`===MORPHOS:SAY===`) —
dann wird nichts committet, der Chat öffnet sich automatisch und die Antwort
führt den Wunsch fort.
