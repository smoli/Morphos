Tastendruck → Ton

Misst, wie lange es vom Tastendruck bis zum Ton dauert und auf welchen Abschnitt die Zeit entfällt. Dieselbe Datei auf jeder Plattform öffnen (Doppelklick genügt), messen, das JSON unten kopieren — die Auswertung macht src/core/audiolatency.ts. Gehört zur Karte c0081.

Bereit.
Auf „Messung starten“ drücken, dann eine beliebige Taste — wieder und wieder.
Arminputdispatchrender devicegesamtPuffern
— noch nichts gemessen —

Alle Werte in Millisekunden, je Abschnitt der Median. input = Ereignis→Handler, dispatch = Handler→start(), render = baseLatency, device = outputLatency.
